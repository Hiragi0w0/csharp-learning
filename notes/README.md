# notes

学習ログ・調査メモ・試作の記録を置く場所。

## 書き方

ファイル名: `YYYYMMDD-テーマ.md`（例: `20260924-async-await.md`）

テンプレート:

```md
# テーマ

## 何をやったか
- 

## わかったこと
- 

## わからなかったこと
- 

## 次にやること
- 

## 参照
- 
```

## ルール

- **わからなかったことを必ず書く。** あとで質問に変えられる形で残す。
- コマンドは実行したものをそのまま貼る（後で再現できるように）。
- AIが出した答えは、理解したら自分の言葉で書き直す。
- 学んだことの「まとめ」だけ書いて終わりにしない。手を動かした記録を残す。
