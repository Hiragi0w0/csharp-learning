# D:\learning

AIエージェントと一緒に学習・開発を進めるための作業スペース。

## 使い方

1. **AIに作業させる前に `AGENTS.md` を読ませる。** ここに作業ルールと前提が書いてある。
2. 学習テーマは `docs/learning-plan.md` から選ぶ。
3. 調べたこと・試したことは `notes/` に残す。あとで自分で読み返せる形にする。
4. 自分の現在地（業務内容・職種）は `docs/profile.md` と `docs/job-map.md`。

## ファイル一覧

| ファイル | 内容 |
|---|---|
| `AGENTS.md` | AIへの作業ルール。役割・進め方・禁止事項・環境メモ |
| `docs/profile.md` | 現在の業務領域と職種の整理（結論・業務比率） |
| `docs/job-map.md` | 職種マップ（該当度★と根拠）、伸ばせる領域 |
| `docs/learning-plan.md` | 学習テーマ候補と進め方 |
| `notes/` | 学習ログ、調査メモ、試作の記録 |

## 自分用メモ

- このフォルダの主目的は「理解して自分で書けるようになること」。成果物は副産物。
- AIには実装を丸投げせず、方針と理由を出させて自分で書く。
